# Team portraits

The team got these portraits from https://bulldogsracing.com/leadership-team on September 22, 2026. This is the 2026–2027 leadership team.

Edit `src/teamData.ts` to add, remove, or reorder members. Edit `src/teamData.ts` to move a member to a different section. To add a member: put the portrait in this folder. Import the file in `src/teamData.ts`. Add one member object with a unique `id`, a `name`, a `role`, and an `image`. The email field is optional. The page renders these arrays with no other change needed.

The group photo is `src/assets/BDRTeam-2600x1733.jpg`. This file is not in this folder. The source leadership page uses the same photo.
