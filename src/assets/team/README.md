# Team portraits

Portraits sourced from https://bulldogsracing.com/leadership-team on September 22, 2026 (2026–2027 leadership).

Edit `src/teamData.ts` to add, remove, reorder, or move members between sections. Add a portrait here, import it in that file, and add a member object with a unique `id`, `name`, `role`, and `image`. Email is optional. The page renders the arrays automatically.

The group photo is the existing `src/assets/BDRTeam-2600x1733.jpg`, also used on the source leadership page.
